# Photographs for the drought-on-the-ground page

Every `.jpg` in this directory is published at `/photos/<name>` and is
referenced by [`landscape.html`](../../landscape.html). Nothing else reads it.

The procedure — file size, format, naming, alt text, caption and the provenance
fields — is
[`docs/operations/landscape-photographs.md`](../../docs/operations/landscape-photographs.md).

Camera data stays in the file, GPS included. These are public places on
public land, and where a photograph was made is part of what it says. The
editing history that records local file paths does not stay. The build
publishes nothing else from here: not this file, and not the `*_original`
backup `exiftool` leaves without `-overwrite_original`.
